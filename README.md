# C++ Lab Works

The 13 experiments in this repository are taken from the **Object Oriented Programming Using C++** lab manual.

## Experiments

1. [University Management System Using Encapsulation and Constructors/Destructors in C++](experiments/experiment_01.cpp)
2. [Runtime Polymorphism Using Virtual Functions and Abstract Classes](experiments/experiment_02.cpp)
3. [Matrix Operations Using Operator Overloading in C++](experiments/experiment_03.cpp)
4. [Generic Stack and Queue Using C++ Templates and Performance Comparison](experiments/experiment_04.cpp)
5. [Student Grade Analyzer Using STL Algorithms and Lambda Expressions](experiments/experiment_05.cpp)
6. [Smart Pointer Behaviour Using RAII and Standard Smart Pointers](experiments/experiment_06.cpp)
7. [Exception Safety in a Bank Account System Using Custom Exception Classes](experiments/experiment_07.cpp)
8. [Move Semantics and Perfect Forwarding for a Resource-Heavy String Class](experiments/experiment_08.cpp)
9. [Singleton, Factory, and Observer Design Patterns in C++](experiments/experiment_09.cpp)
10. [Multi-Threaded Producer-Consumer System Using C++](experiments/experiment_10.cpp)
11. [Type-Safe Unit Conversion Library Using C++ Templates and constexpr](experiments/experiment_11.cpp)
12. [Mini File System Simulator Using File I/O Streams and Binary Serialization](experiments/experiment_12.cpp)
13. [Generic Data Pipeline Using C++20 Modules, Concepts, and Ranges](experiments/experiment_13/)

## Notes

- Experiments 1–12 are individual `.cpp` files.
- Experiment 13 uses C++20 modules and is split into `pipeline.cppm`, `main.cpp`, and `CMakeLists.txt`.
